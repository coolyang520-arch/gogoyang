# 這台機車開過了沒

巡查機車違停用的 Android App。不辨識車牌文字，而是比對車尾照片。

## 使用方式

1. **第一圈・記錄**：開完單後，把機車車尾放進白框、車牌對準黃色虛線框，按「拍照記錄」（也可點畫面或按音量鍵）。
   - 照片會和今天已記錄的每一台比對；若已經記錄過，不會重複新增。
2. **第二圈・巡查**：同樣拍車尾，按「拍照查詢」。
   - 綠色「已開單」：只有一台記錄符合，並排顯示當時的照片供對照車牌。
   - 紅色「未開單」：今天沒有這台，可直接「標記為已開單」。
   - 黃色：有點像或有好幾台很像，App 不會自己猜，請點選正確的照片。

## 一張照片只對應一台車

- 只拍白框內的範圍，旁邊停的其他機車不會被拍進比對。
- 判定時最像的那台分數必須至少是第二像的 2 倍才算「同一台」；兩台以上接近時一律請使用者選。
- 第一圈新增前會先比對，同一台不會被記成兩筆。

## 比對原理

用 OpenCV 的 ORB 特徵點比對兩張照片，再以 RANSAC 求透視變換，只計算幾何一致的特徵點；
車牌框內的特徵點算兩倍分數（車牌是分辨同款車的關鍵）。門檻在 `Decide.kt`，畫面左下角會顯示
「最像 / 次像」分數，可依實際使用情況調整 `STRONG`、`WEAK`、`MARGIN`。

資料（照片與特徵）只存在手機上，每天自動清空。
